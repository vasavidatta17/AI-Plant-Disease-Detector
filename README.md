# 🌱 AI Plant Disease Detector

An AI-based system to detect plant diseases from leaf photos.

## Features
- Detects 44 diseases across 13 plant types
- Shows treatment advice for each disease
- Simple web interface — works on phone and computer
- No hardware required

## Plants Supported
Tomato, Potato, Corn, Apple, Grape, Cherry, Pepper,
Strawberry, Peach, Orange, Rice, Wheat, Squash

## How to Run
pip install -r requirements.txt
python app.py

## Dataset
PlantVillage Dataset — 54,000+ leaf images, 38 disease classes

## Tech Stack
- Python
- Gradio (Web Interface)
- NumPy (Image Processing)
- Pillow (Image Handling)

## Real World Application
Helps farmers detect crop diseases early by simply
uploading a photo of the affected leaf.
